# Portfolio de Sofiane Meziane

Site statique sans outil de compilation ni dépendance CSS externe.

## Fichiers à modifier

- `index.html` : structure et contenu sémantique de la page.
- `styles.css` : tous les styles, le thème sombre et les animations.
- `script.js` : traductions, thème, contenu dynamique et interactions.
- `images/` : CV et ressources locales.

Pour le prévisualiser, ouvrez `index.html` dans un navigateur ou servez ce dossier avec un serveur statique. Aucune installation n'est nécessaire.
